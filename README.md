# MERN Polls App (MongoDB, Express, React, Node)
Features: signup (name/username/email), login with username or email, live username/email availability check,
JWT auth, create poll (2-6 choices, expiry in days+hours), paginated feed (Load more), one vote per user,
results after voting or expiry with your choice highlighted, time-left, delete own poll, profile pages (polls + votes).
## Server
MongoDB chalu rakho, phir: cd server && npm install && npm start   (http://localhost:5000)
## Frontend
cd frontend && npm install && npm run dev   (http://localhost:5173)
